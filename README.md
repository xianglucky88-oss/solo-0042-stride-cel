# 步格 · 游戏动画事件与位移校样

将定时关键帧和窗口编译到固定采样帧，支持镜像和循环首尾检查；校样后冻结并下载引擎可用的帧表。

## 启动

需要 Node.js 20 或更新版本，无需安装第三方依赖。

```sh
npm start
```

浏览器打开 `http://127.0.0.1:8741`。项目只监听本机回环地址；用 `PORT` 可换端口。`MEDIA_HOME` 可指定数据目录，默认 `.local/`，不进 Git。

## 校样

建议先切到 20 FPS 并拖动时间线，比较同一作用区的采样边界与朝向切换。

可以导入 JSON，或者在「源文档」区域编辑。获取可导入样例：`curl -s http://127.0.0.1:8741/api/demo | node -e 'process.stdin.on("data",c=>s+=c).on("end",()=>console.log(JSON.stringify(JSON.parse(s).document,null,2)));let s=""'`。
更新校样只计算不落盘；冻结会写入版本库，下载原始 `.json` 资产。可在「冻结版本」中复取已保存版本。

### 成套冻结

同一段动作需要同时交付两档刷新配置、每档左右两个朝向时，在「成套冻结」里填两档帧率（6–60 的不同整数），可点名每份成品都必须看得到的作用区。一次请求渲染四份独立帧表：

- 每份成品与用同一原稿、同一帧率、同一朝向单独冻结的字节完全一致，可单独交给引擎。
- 两档顺序写反、请求字段重排或两人同时提交同一交付内容，都只得到同一个套件版本号。
- 若某个必需作用区在任一成品没有采样点，会按帧率与朝向列出缺项并整体拒绝，磁盘上不留可打开的半套，草稿仍可预览。例如 40–75 ms 的作用区在 30 fps 可见、12 fps 两朝向都不可见；把关闭时间改到 90 ms 后四份即可凭同一版本号查询并各自下载。
- 重启服务或随后修改草稿，旧套件仍交付冻结当时的四份原字节；此前单独签出的冻结链接也照常可用。

套件接口为 `POST /api/suites`、`GET /api/suites`、`GET /api/suites/:id` 与 `GET /api/suites/:id/:fps-:facing/asset`。
